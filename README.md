# wherewasi

A tiny CLI tool that remembers where you left off.

## Installation

```bash
pip install wherewasi
```

## Usage

Run:

```bash
wherewasi
```

Write your note and walk away. When you come back, run `wherewasi` again to see where you left off.

Missed it? Show your latest note again:

```bash
wherewasi show
```

Want to see your previous notes?

```bash
wherewasi log
```
